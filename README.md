## 🛠️ Hướng Dẫn Cài Đặt Vào Chrome (Chỉ mất 30 giây)

### Bước 1: Mở trang quản lý Extension của Chrome
* Mở trình duyệt Google Chrome.
* Gõ vào thanh địa chỉ: `chrome://extensions` và bấm **Enter**.

### Bước 2: Bật "Chế độ dành cho nhà phát triển" (Developer mode)
* Nhìn lên góc trên cùng bên phải màn hình.
* Bật công tắc **Chế độ dành cho nhà phát triển (Developer mode)** sang màu xanh.

### Bước 3: Nạp tiện ích vào Chrome
* Bấm vào nút **Tải tiện ích đã giải nén** (Load unpacked) ở góc trên bên trái.
* Chọn thư mục:
  `/Users/nguyenanhtuan/MMO/lazyman-ai-assistant`
* Bấm **Select / Open** (Chọn).

👉 **Xong!** Biểu tượng LazyMan AI sẽ xuất hiện trên thanh công cụ của Chrome. Bạn hãy ghim (pin) nó lên thanh công cụ.

## 🔑 Hướng Dẫn Lấy Gemini API Key Miễn Phí

1. Truy cập: [Google AI Studio (aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey)
2. Đăng nhập bằng tài khoản Google bất kỳ của bạn.
3. Bấm nút **Create API Key** (Tạo khóa API) -> Chọn một dự án bất kỳ hoặc tạo mới.
4. Copy chuỗi khóa có dạng `AIzaSy...`.
5. Mở tiện ích LazyMan AI trên Chrome -> Bấm vào biểu tượng bánh răng **⚙️ (Cài đặt)** -> Dán khóa vào -> Bấm **Lưu cấu hình**.
